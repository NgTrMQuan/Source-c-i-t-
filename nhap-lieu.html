Nhập link bộ cài

Dán link tải từ Autodesk, trang sẽ tự nhận phần mềm, năm và thứ tự Part. Kiểm tra lại, bấm “Thêm vào danh sách”, xong thì tải về file data.json mới để cập nhật lên GitHub. Không cần biết JSON.

1Dán link

Mỗi dòng một link. Có thể dán cả đoạn văn có lẫn chữ “Part 1:”, trang chỉ lấy các link.

2Danh sách thay đổi

Các phiên bản sẽ được ghi vào data.json. Danh sách được giữ lại nếu bạn tải lại trang.

Mở data.json trên GitHub ↗
  1. Bấm Sao chép nội dung (hoặc tải file về).
  2. Bấm Mở data.json trên GitHub, đăng nhập, bấm Ctrl+A rồi dán đè nội dung mới.
  3. Bấm Commit changes… → Commit changes. Khoảng 1–2 phút sau trang Bộ cài đặt sẽ cập nhật, và hệ thống tự kiểm tra các link mới.
Phiên bản đã có trên trang: link mới sẽ được thêm vào, link trùng (cùng tên file) được bỏ qua. Muốn thay link cũ (ví dụ link hết hạn), tích “Thay toàn bộ link cũ” trước khi thêm.
